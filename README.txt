HARIOM COLLECTION — MOBILE PWA STARTER

WHAT THIS IS
A mobile-friendly installable web app prototype for HARIOM COLLECTION.
It can be hosted free on GitHub Pages and added to an Android phone home screen.

IMPORTANT LIMITATIONS OF THIS FIRST FREE VERSION
- This is a front-end prototype, not yet a production Android APK.
- Product changes and customer details are stored only in the browser/device using localStorage.
- The demo admin passcode is HARIOM2026. This is NOT secure authentication. Do not publish sensitive admin features with this passcode.
- WhatsApp ordering opens a message to shop number 9001257658.
- No live payment gateway, cloud inventory sync, secure customer login, or cross-device order database is connected yet.
- Replace the sample products/prices/images with actual shop inventory before launch.
- For secure multi-device customer/admin data, a backend (e.g. Firebase) must be configured. Its free tier can be used within quota, but setup is required.

PUBLISH FREE USING GITHUB PAGES (PHONE BROWSER)
1. Sign in to github.com.
2. Create a Public repository named hariom-collection.
3. Upload all files and the icons folder from this ZIP (keep folder structure).
4. In repository Settings > Pages, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. The website address will appear in Settings > Pages.
7. Open that address in Chrome on Android > menu (three dots) > Add to Home screen / Install app.
